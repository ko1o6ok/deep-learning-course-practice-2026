1. Вывод формул для градиентов¶

Сначала рассмотрим случай одного примера. Обозначим нейросеть следующим образом:

  • Вход: $x \in \mathbb{R}^{w h}$. Одноканальное изображение размером $w \times h$
  • Аффинное преобразование первого (скрытого) слоя: $z^{(1)} = W^{(1)}x+b^{(1)}$. $z^{(1)} \in \mathbb{R}^{s}$
  • Активация первого (скрытого) слоя: $a^{(1)} = \mathrm{ReLU}(z^{(1)})$. $a^{(1)} \in \mathbb{R}^{s}$
  • Аффинное преобразование второго (выходного) слоя: $z^{(2)} = W^{(2)}a^{(1)}+b^{(2)}$. $z^{(2)} \in \mathbb{R}^{k}$
  • Выход, активация второго (выходного) слоя: $a^{(2)} = \mathrm{softmax}(z^{(2)})$. $a^{(2)} \in \mathbb{R}^{k}$

Пусть ожидаемый выход в терминах one-hot-encoding есть $y \in \{0,1\}^k$, где $k$ количество классов. Для изображения класса $i$ имеем $y = e_i$, где $e_i$ --- $i$-й базисный вектор. В качестве лосс-функции используем кросс-энтропию $$ L(a^{(2)}) = - \sum_{j = 1}^k y_j \log{a^{(2)}_j} = - y^T\log{a^{(2)}} . $$

Нам необходимо последовательно посчитать величины $\frac{\partial L}{\partial W^{(1)}}, \frac{\partial L}{\partial b^{(1)}}, \frac{\partial L}{\partial W^{(2)}}, \frac{\partial L}{\partial b^{(2)}}$.

Посчитаем необходимые градиенты и якобианы. Для начала градиент лосса $$\frac{\partial L}{\partial a_i^{(2)}} = - \frac{y_i}{a_i^{(2)}}, i = 1, \ldots, k.$$ Затем якобиан softmax-а $$\frac{\partial a_i^{(2)}}{\partial z_j^{(2)}} = \frac{\partial }{\partial z_j^{(2)}} \Bigl( \frac{e^{z_i^{(2)}}}{\sum_{l = 1}^{k}e^{z_l^{(2)}}}\Bigr) = \frac{\Bigl(\sum_{l = 1}^{k}e^{z_l^{(2)}}\Bigr)\frac{\partial }{\partial z_j^{(2)}}(e^{z_i^{(2)}}) -e^{z_i^{(2)}} \frac{\partial }{\partial z_j^{(2)}}\Bigl(\sum_{l = 1}^{k}e^{z_l^{(2)}}\Bigr)}{\Bigl(\sum_{l = 1}^{k}e^{z_l^{(2)}}\Bigr)^2} = \frac{\Bigl(\sum_{l = 1}^{k}e^{z_l^{(2)}}\Bigr)e^{z_i^{(2)}} \delta_{i,j} -e^{z_i^{(2)}} e^{z_j^{(2)}}}{\Bigl(\sum_{l = 1}^{k}e^{z_l^{(2)}}\Bigr)^2} = a_i^{(2)} (\delta_{i,j} - a_j^{(2)}),$$ где $\delta_{i,j} = \begin{cases} 1, i=j\\ 0, i\not=j\end{cases}$ --- дельта Кронекера. Теперь запишем $$\frac{\partial L}{\partial z_j^{(2)}} = \sum_{i = 1}^k \frac{\partial L}{\partial a_i^{(2)}}\frac{\partial a_i^{(2)}}{\partial z_j^{(2)}} = \sum_{i = 1}^k - \frac{y_i}{a_i^{(2)}} a_i^{(2)} (\delta_{i,j} - a_j^{(2)}) = -y_j + a_j^{(2)} \underbrace{\sum_{i = 1}^k y_i}_{=1} = a_j^{(2)} - y_j,$$ откуда $$\frac{\partial L}{\partial z^{(2)}} =a^{(2)} - y = g^{(2)}.$$ Теперь мы будем считать $ g^{(1)} = \frac{\partial L}{\partial z^{(1)}}$. Чтобы это сделать, сначала получим $$ \frac{\partial L}{\partial a_j^{(1)}} = \sum_{i=1}^k \frac{\partial L}{\partial z_i^{(2)}} \frac{\partial z_i^{(2)}}{\partial a_j^{(1)}} = \sum_{i=1}^k g_i^{(2)} W_{i,j}^{(2)} = W_j^{(2)T} g^{(2)}, $$ откуда $$ \frac{\partial L}{\partial a^{(1)}} = W^{(2)T} g^{(2)}. $$ Теперь заметим, что $a_i^{(1)} = \mathrm{ReLU}(z_i^{(1)}) = \max{(0,z_i^{(1)})}$, производная $$ \mathrm{ReLU}'(z) = \begin{cases} 1, z >0 \\ 0, z \leq 0\end{cases}. $$ Отсюда $$ \frac{\partial L}{\partial z_l^{(1)}} = \frac{\partial L}{\partial a_l^{(1)}} \mathrm{ReLU}'(z_l^{(1)}) $$ и $$ g^{(1)} = \frac{\partial L}{\partial z^{(1)}} = (W^{(2)T} g^{(2)}) \odot \mathrm{ReLU}'(z^{(1)}) = (W^{(2)T} g^{(2)}) \odot 1[z^{(1)} > 0], $$ где $\odot$ означает поэлементное умножение. Далее переходим к подсчёту искомых градиентов: $$ z_i^{(2)} = \sum_{j = 1}^s W_{i,j}^{(2)}a_j^{(1)}+b_i^{(2)}, $$ $$ \frac{\partial z_i^{(2)}}{\partial W_{i,j}^{(2)}} = a_j^{(1)}, $$ $$ \frac{\partial L}{\partial W_{i,j}^{(2)}} = g^{(2)}_i a_j^{(1)}, $$ $$ \frac{\partial L}{\partial W^{(2)}} = g^{(2)} a^{(1)T}. $$ Аналогично $$ \frac{\partial L}{\partial b^{(2)}} = g^{(2)}. $$ Таким же образом получаем $$ \frac{\partial L}{\partial W^{(1)}} = g^{(1)} x^{T} $$ и $$ \frac{\partial L}{\partial b^{(1)}} = g^{(1)}. $$ Когда у нас не один пример, а пачка из $N$ примеров, батч, мы меняем лосс на среднюю кросс-энтропию по пачке. Обозначим большими буквами те же величины, собранные в матрицы по столбцам-примерам. Тогда $$ L = - \frac{1}{N} \sum_{n=1}^N y_n^T\log{a_n^{(2)}} = - \frac{1}{N} \sum_{n=1}^N \sum_{j=1}^k Y_{j,n}\log{A_{j,n}^{(2)}} $$ и константу мы можем внести лишь в $$ G^{(2)} = \frac{1}{N} (A^{(2)} - Y), $$ поскольку $G^{(1)}$ и частные производные по весам и сдвигам зависят от этой величины линейно. Тогда имеем $$ G^{(1)} = \bigl(W^{(2)\top} G^{(2)}\bigr) \odot \mathbf{1}[Z^{(1)} > 0],, $$ $$ \frac{\partial L}{\partial W^{(2)}} = G^{(2)} A^{(1)T}, $$ $$ \frac{\partial L}{\partial b^{(2)}} = G^{(2)} 1_N, $$ где $1_N$ --- вектор-столбец из $N$ единиц. Далее $$ \frac{\partial L}{\partial W^{(1)}} = G^{(1)} X^{T}, $$ $$ \frac{\partial L}{\partial b^{(1)}} = G^{(1)} 1_N. $$

Пусть скорость обучения есть $\eta$, тогда шаг градиентного спуска в простейшей форме имеет вид $$ \begin{cases} W^{(1)}_{\mathrm{new}} = W^{(1)}_{\mathrm{old}} - \eta \frac{\partial L}{\partial W^{(1)}};\\ b^{(1)}_{\mathrm{new}} = b^{(1)}_{\mathrm{old}} - \eta \frac{\partial L}{\partial b^{(1)}};\\ W^{(2)}_{\mathrm{new}} = W^{(2)}_{\mathrm{old}} - \eta \frac{\partial L}{\partial W^{(2)}};\\ b^{(2)}_{\mathrm{new}} = b^{(2)}_{\mathrm{old}} - \eta \frac{\partial L}{\partial b^{(2)}}.\\ \end{cases} $$

def one_hot(y, k=10):
    Y = np.zeros((y.shape[0], k), dtype=np.float32)
    Y[np.arange(y.shape[0]), y] = 1.0
    return Y

3. Инициализация весов¶

Мы применяем метод инициализации весов через нормальное распределение с нулевым средним и дисперсией порядка $\frac{2}{\text{размер вх. слоя}}$ (He). Это нужно, потому что активация $\mathrm{ReLU}$ обнуляет примерно половину нейронов и чтобы второй момент после активации совпал со вторым моментом до активации нам нужно его масштабировать. Так скрытый слой не схлопывает сигнал в ноль и не раздувает его.

4. Forward¶

In [10]:
# Основные функции
def relu(Z):
    return np.maximum(Z, 0.0) # Поэлементный максимум

# Для softmax используем численный трюк: если домножить и числитель и знаменатель дроби на одно и то же число, то значение дроби не поменяется, 
# поэтому можно сдвинуть значения на константу, чтобы экспоненты НЕ взрывались
def softmax(Z):
    Zs = Z - Z.max(axis=0, keepdims=True) # Вычитаем max по классам в каждом примере
    E = np.exp(Zs)
    return E / E.sum(axis=0, keepdims=True)

def forward(X, W1, b1, W2, b2):
    Z1 = W1 @ X + b1# (s, N)
    A1 = relu(Z1) # (s, N)
    Z2 = W2 @ A1 + b2 # (k, N)
    A2 = softmax(Z2) # (k, N)
    cache = (X, Z1, A1, Z2, A2)
    return A2, cache

5. Backward¶

Мы используем то, что вывели в теории, но поделим лосс на размер батча, чтобы было усреднение по батчу. Для этого достаточно поделить выражение с $g_2$ на $N$ и градиенты сами подтянутся.

In [12]:
N = 32 # Размер батча

def cross_entropy(A2, Y, eps=1e-12):
    # средняя CE по столбцам; Y — one-hot (k, N)
    return float(-np.sum(Y * np.log(A2 + eps)) / N) # Для численной устойчивости добавляем регуляризацию
In [13]:
def backward(Y, cache, W2):
    X, Z1, A1, Z2, A2 = cache

    G2 = (A2 - Y) / N # Для усреднения по батчу
    dW2 = G2 @ A1.T
    db2 = G2.sum(axis=1, keepdims=True) # Сумма по батчу

    G1 = (W2.T @ G2) * (Z1 > 0)
    dW1 = G1 @ X.T
    db1 = G1.sum(axis=1, keepdims=True) # Сумма по батчу

    return dW1, db1, dW2, db2

# Точность классификации
def accuracy(A2, y):
    return float(np.mean(A2.argmax(axis=0) == y))

# Ошибка классицикации
def class_error(A2, y):
    return float(np.mean(A2.argmax(axis=0) != y))

import time

n_batches = n_train // N

for epoch in range(n_epochs):
    t0 = time.perf_counter()

    perm = rng.permutation(n_train)
    X_shuf = X_train[:, perm]
    Y_shuf = Y_train[:, perm]

    epoch_loss = 0.0
    for t in range(n_batches):
        sl = slice(t * N, (t + 1) * N)
        X_b = X_shuf[:, sl]
        Y_b = Y_shuf[:, sl]

        A2, cache = forward(X_b, W1, b1, W2, b2)
        epoch_loss += cross_entropy(A2, Y_b)

        dW1, db1, dW2, db2 = backward(Y_b, cache, W2)
        W1 -= lr * dW1
        b1 -= lr * db1
        W2 -= lr * dW2
        b2 -= lr * db2

    A2_tr, _ = forward(X_train, W1, b1, W2, b2)
    train_err = class_error(A2_tr, y_train)
    dt = time.perf_counter() - t0
    mean_loss = epoch_loss / n_batches

    hist_epoch.append(epoch + 1)
    hist_loss.append(mean_loss)
    hist_train_err.append(train_err)
    hist_time.append(dt)

    print(
        f"epoch {epoch+1:02d}  "
        f"train error {train_err:.4f} ({100*train_err:.2f}%)  "
        f"time {dt:.2f} s"
    )

hist_epoch = np.array(hist_epoch)
